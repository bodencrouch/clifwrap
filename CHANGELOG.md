# Changelog

All notable changes are listed here. Version sections and release notes are generated by [release-please](https://github.com/googleapis/release-please) from conventional commits.

## [0.1.0](https://github.com/bodencrouch/clifwrap/releases/tag/v0.1.0) (2026-07-25)

Initial release.

- Multi-account CLI failover wrapper with quota-aware capacity control
- Built-in example providers (`searchcli`, `scrapecli`) in `providers.toml`
- Declarative account import, queue/replay, auth management, and status tooling
- CI, release validation, and anonymity checks for the public tree
